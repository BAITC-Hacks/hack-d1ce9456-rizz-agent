# Разбор обращений

Скрипт читает пять обращений из `messages.txt`. Для каждого он определяет
категорию: `справка`, `жалоба` или `другое`, а затем печатает черновик ответа
на русском языке. Для классификации используются простые правила по словам —
подключение к ИИ не требуется.

## Запуск

Нужен Node.js. В корне репозитория выполните:

```bash
node classify_messages.js
```

## Результат

В консоли появятся все пять исходных обращений, их категории и черновики
ответов. Например, вопрос о справке будет отнесён к категории `справка`,
сообщения о холодной еде и Wi-Fi — к категории `жалоба`, а просьба записаться
на консультацию — к категории `другое`.
