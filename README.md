# ИИ-агент: классификатор обращений

Небольшой автономный агент разбирает обращения студентов: определяет их категорию и составляет черновик ответа на русском языке.

## Что делает

1. Читает обращения из `messages.txt` (по одному в строке).
2. Классифицирует каждое как `справка`, `жалоба` или `другое`.
3. Показывает правило, по которому была выбрана категория.
4. Создаёт вежливый черновик ответа с полезным следующим шагом.

Для решения не нужны библиотеки, интернет или API-ключ: логика агента находится в `agent.py`. Это делает демонстрацию воспроизводимой.

## Запуск

Требуется Python 3.10 или новее.

```bash
python agent.py
```

Можно передать другой файл обращений:

```bash
python agent.py --input my_messages.txt
```

## Проверка

```bash
python -m unittest -v
```

## Получившийся результат

На подготовленных пяти обращениях агент выдаёт:

| Обращение | Категория |
| --- | --- |
| Справка о месте учёбы | справка |
| Очередь и холодная еда | жалоба |
| Запись на консультацию | справка |
| Не работает Wi-Fi | жалоба |
| Парковка для гостей | справка |

Каждый результат дополнен черновиком ответа. Правила классификации легко расширяются: достаточно добавить ключевые слова или отдельную ветку в `classify` и `draft_response`.




# Разбор обращений

Скрипт читает пять обращений из `messages.txt`. Для каждого он определяет
категорию: `справка`, `жалоба` или `другое`, а затем печатает черновик ответа
на русском языке. Для классификации используются простые правила по словам —
подключение к ИИ не требуется.

## Запуск

Нужен Node.js. В корне репозитория выполните:

```bash
node classify_messages.js
```

## Результат

В консоли появятся все пять исходных обращений, их категории и черновики
ответов. Например, вопрос о справке будет отнесён к категории `справка`,
сообщения о холодной еде и Wi-Fi — к категории `жалоба`, а просьба записаться
на консультацию — к категории `другое`.
