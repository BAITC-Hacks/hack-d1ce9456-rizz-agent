# ИИ-агент: классификатор обращений Задания 1

Небольшой автономный агент разбирает обращения студентов: определяет их категорию и составляет черновик ответа на русском языке.

## Что делает

1. Читает обращения из `messages.txt` (по одному в строке).
2. Классифицирует каждое как `справка`, `жалоба` или `другое`.
3. Показывает правило, по которому была выбрана категория.
4. Создаёт вежливый черновик ответа с полезным следующим шагом.

Для решения не нужны библиотеки, интернет или API-ключ: логика агента находится в `agent.py`. Это делает демонстрацию воспроизводимой.

## Запуск

Требуется Python 3.10 или новее.

```bash
python agent.py
```

Можно передать другой файл обращений:

```bash
python agent.py --input my_messages.txt
```

## Проверка

```bash
python -m unittest -v
```

## Получившийся результат

На подготовленных пяти обращениях агент выдаёт:

| Обращение | Категория |
| --- | --- |
| Справка о месте учёбы | справка |
| Очередь и холодная еда | жалоба |
| Запись на консультацию | справка |
| Не работает Wi-Fi | жалоба |
| Парковка для гостей | справка |

Каждый результат дополнен черновиком ответа. Правила классификации легко расширяются: достаточно добавить ключевые слова или отдельную ветку в `classify` и `draft_response`.




# Event Filter Задания 2

Этот проект читает файл `events.json` со списком событий в формате NDJSON и
отбирает только те события, у которых поле `level` равно `critical`.

Скрипт есть в двух вариантах:
- `filter_alerts.py` — версия на Python
- `filter_alerts.js` — версия на JavaScript/Node.js

## Как устроен файл `events.json`

Каждая строка файла — отдельный JSON-объект. Пример:

```json
{"event":"disk 90%","level":"critical"}
{"event":"user login","level":"info"}
{"event":"payment failed","level":"critical"}
```

Где:
- `event` — текст события
- `level` — важность события: `info`, `warn`, `critical` и т.д.

## Что делает программа

Программа:
1. открывает `events.json`
2. читает все строки
3. парсит JSON
4. оставляет только события с `level == "critical"`
5. выводит их в консоль
6. печатает итоговое количество критичных событий

## Запуск на Python

```bash
python filter_alerts.py
```

## Запуск на Node.js

```bash
node filter_alerts.js
```

## Пример вывода

```text
disk 90%
payment failed
db timeout
критичных 3
```

## Цель проекта

Проект демонстрирует простой способ фильтрации событий по уровню важности в
структурированном потоке данных и может использоваться как базовый пример для
обработки логов или событийных данных.
